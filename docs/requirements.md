# Требования

«Быки и коровы» — логическая игра в Telegram Mini App: сервер загадывает число из разных цифр, игрок угадывает. Статистика игрока и общий рейтинг. Правила — [rules.md](rules.md), решения — [decisions.md](decisions.md).

Это вторая версия уже выпущенного продукта (первая версия — только справка о поведении): та же игра, написанная заново без слоёв «на вырост». Цель — показать, что те же свойства достигаются кратно меньшим кодом.

## Что видит игрок

- **Mini App** — единственный клиент. Экраны и оформление — как у Mini App первой версии ([макет](assets/webapp-mockup.html)): заглавный, игра, подтверждение завершения, итог партии, статистика и рейтинг. Анимация победы.
- **Бот** — только вход: описание в пустом чате и ответ на `/start` с кнопкой «Играть». Mini App открывается и кнопкой меню.
- **Языки:** русский и английский. Каждый написан отдельно, не переводом. Язык хранится на сервере; при первом входе — из настроек Telegram (`ru…` → ru, остальное → en).
- **Доступность:** подписи для экранного диктора (проверка — VoiceOver на iPhone SE), кнопки не меньше 44 пикселей, видимый фокус, «уменьшить движение» отключает анимацию.

## Свойства, которые защищают систему

- Правила и проверки — только на сервере. Клиенту не доверяем.
- Загаданное число не уходит клиенту, пока партия идёт.
- Вход — по подписи Telegram (`initData`) со сроком годности. `initData` не пишется в логи.
- Входа в обход подписи на сервере нет: подпись для разработки делает только сервер разработки Vite, в сборку она не попадает. Это проверяет тест.
- Повтор запроса хода не засчитывает ход дважды.
- Ограничение частоты запросов.
- HTTPS. Секреты — в `.env`, не в репозитории.
- Схема базы — только миграциями. Ограничения в базе — последний рубеж.
- Резервные копии вне сервера и проверенное восстановление.

## Масштаб

| Требование | Значение |
|---|---|
| Игроков в базе | 10 000 |
| Одновременно играют | 1 000 |
| Время хода | 95% быстрее 500 мс |

Для каждого запроса записано, как его цена растёт с объёмом данных ([decisions.md](decisions.md), «Цена запросов»). Проверка — один нагрузочный замер с базой реалистичного объёма.

## Не делаем

- Игру в чате бота — только Mini App.
- Журнал событий и дашборды — вопросы задаются SQL-запросами к партиям и ходам.
- Перенос данных игроков из первой версии.
- Другие режимы игры и выбор длины числа игроком.

## Окружение

- **Сервер:** облачная ВМ (ARM). Рядом работают другие проекты — их не трогаем. Новая версия заменяет первую на том же домене DuckDNS.
- **Локально:** Windows 10, VS Code, Docker Desktop, Node 24, pnpm.
- **Бюджет:** ноль.
