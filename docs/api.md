# API и данные

Сервер отдаёт данные и коды ошибок, а не текст: текст на языке игрока собирает Mini App. Правила — [rules.md](rules.md).

## Общее

- Адреса начинаются с `/api`. Тела — JSON; тело другого типа сервер не читает — запросу, которому тело нужно, это даст `request.invalid`.
- **Вход:** каждый запрос несёт `Authorization: tma <initData>` — строку, которую Telegram передаёт Mini App при открытии. Сервер проверяет подпись (HMAC-SHA256 с ключом из токена бота) и срок — 24 часа от `auth_date`. Игрок определяется **только** по проверенным данным. `initData` не пишется в логи.
- **Проверка номера хода:** ход несёт номер, который он получит. Повтор запроса или ход со старого экрана получает `409`, а не засчитывается дважды.
- **Ограничение частоты:** 120 запросов в минуту на игрока; 30 в минуту на IP для запросов без верной подписи. Превышение — `429` и заголовок `Retry-After`. Счётчики — в памяти сервера: он один.

## Запросы

| Запрос | Что делает | Успех |
|---|---|---|
| `POST /api/session` | Открытие Mini App: зарегистрировать или обновить игрока, вернуть его и последнюю партию | `200` |
| `PATCH /api/me` | Сменить язык | `200` |
| `POST /api/games` | Новая партия | `201` |
| `POST /api/games/:id/guesses` | Ход | `200` |
| `POST /api/games/:id/abandon` | Завершить партию | `200` |
| `GET /api/stats` | Своя статистика и рейтинг | `200` |
| `POST /api/errors` | Ошибка в коде страницы → в лог сервера | `202` |
| `GET /health` | Сервер жив; снаружи недоступен | `200` |

### `POST /api/session`

Тело пустое: username и язык Telegram берутся из проверенных `initData`, не из тела. Язык выбирается **только при первом входе** (`ru…` → `ru`, остальное → `en`); username обновляется при каждом.

```json
{
  "player": { "id": 12, "username": "anna_k", "language": "ru" },
  "game": null,
  "gameLength": 4
}
```

`game` — последняя партия (`GameView`) или `null`, если партий не было. `gameLength` — сколько цифр в новой партии: Mini App показывает его в правилах до первой игры, своей константы у неё нет.

### `PATCH /api/me`

`{ "language": "en" }` → `{ "player": … }`.

### `POST /api/games/:id/guesses`

`{ "guess": "0123", "attempt": 3 }` → `GameView`. `guess` — строка: ведущий ноль в числе потерялся бы.

### `GET /api/stats`

```json
{
  "window": 20,
  "minWins": 5,
  "me": {
    "gamesPlayed": 12, "wins": 10, "bestResult": 4,
    "averageAttempts": 6.4, "averageGames": 12, "recentWins": 9, "place": 14
  },
  "top": [
    { "place": 1, "playerId": 3, "username": "anna_k", "averageAttempts": 5.4, "recentWins": 17 },
    { "place": 2, "playerId": 7, "username": null, "averageAttempts": 5.9, "recentWins": 8 }
  ]
}
```

- `top` — 10 первых мест. Имя без username Mini App пишет как «Игрок #7» по `playerId`. Id в Telegram не отдаётся никогда.
- `me.place` — `null`, пока игрок не в рейтинге; `averageAttempts` — `null` до первой игры; `bestResult` — `null` до первой победы. Из `recentWins` и `minWins` Mini App считает, сколько побед не хватает.
- Средние округлены до двух знаков, места считаются по точным значениям.

## GameView

```json
{
  "id": 42,
  "status": "active",
  "length": 4,
  "attempts": [{ "number": 1, "guess": "0123", "bulls": 0, "cows": 2 }],
  "remaining": 1260,
  "secret": null
}
```

- `remaining` — сколько чисел ещё подходит; `null` до первого хода.
- `secret` — **`null`, пока партия `active`**. Это проверяет тест на каждый ответ с партией.

## Ошибки

Формат один: `{ "error": { "code": "game.not_active" } }`; для `request.invalid` — ещё `details` (какое поле не прошло).

| Статус | Код | Когда |
|---|---|---|
| `400` | `request.invalid` | Тело не по схеме |
| `400` | `guess.invalid_format`, `guess.wrong_length`, `guess.digits_not_unique` | Неверный ход ([rules.md](rules.md)) |
| `401` | `auth.unauthorized` | Нет подписи или она неверна |
| `401` | `auth.init_data_expired` | Подпись верна, но данные старше 24 часов — Mini App просит открыть её заново. Сообщается только при верной подписи |
| `404` | `route.not_found` | Нет такого адреса. Под `/api` сначала проверяется подпись |
| `404` | `player.not_found` | Игрок не зарегистрирован (например, база очищена) — Mini App вызывает `/api/session` и повторяет |
| `404` | `game.not_found` | Партии нет **или она чужая** — не раскрываем, что она существует |
| `409` | `game.not_active` | Ход или завершение в законченной партии |
| `409` | `game.already_active` | Новая партия при идущей |
| `409` | `guess.attempt_mismatch` | Номер хода не тот — Mini App перерисовывает экран по данным сервера |
| `429` | `rate.limited` | Слишком много запросов |
| `500` | `internal.error` | Непредвиденная ошибка; подробности — только в логе |

## Таблицы

Схема меняется только миграциями Kysely, они применяются при старте сервера. Ограничения в базе — последний рубеж.

**`players`**

| Поле | Правила |
|---|---|
| `id` | автонумерация; он же «Игрок #12» |
| `telegram_id` | уникальный; наружу не отдаётся |
| `username` | может быть пустым |
| `language` | `CHECK`: `ru` или `en` |
| `created_at` | |
| `rating_average`, `rating_wins`, `rating_games` | сводка рейтинга; все три пусты до первой игры (`CHECK`) |

Индекс для рейтинга: (`rating_average`, `rating_wins` по убыванию, `id`) по строкам со сводкой.

**`games`**

| Поле | Правила |
|---|---|
| `id`, `player_id` | внешний ключ на `players` |
| `length` | `CHECK`: 1–10 |
| `secret` | `CHECK`: только цифры, длина = `length`, без повторов |
| `status` | `CHECK`: `active`, `won`, `abandoned` |
| `attempt_count` | число ходов; меняется в той же транзакции, что и ход |
| `started_at`, `finished_at` | `CHECK`: `finished_at` пусто ⇔ `status = active` |

- Не больше одной активной партии у игрока — частичный уникальный индекс по `player_id` для `status = active`.
- `attempt_count` хранится, чтобы статистика не считала ходы по таблице ходов: так в v1 Prisma `_count` прочитала ходы всей базы.

**`guesses`**

| Поле | Правила |
|---|---|
| `game_id`, `attempt_no` | первичный ключ — второй ход №3 в партии база не сохранит |
| `value` | `CHECK`: только цифры |
| `bulls`, `cows` | `CHECK`: ≥ 0 |
| `remaining` | сколько чисел подходило после хода |
| `created_at` | время хода — для поиска решателей потом |

**`bot_greetings`** — приветствие бота в каждом чате: `telegram_id` (первичный ключ), `chat_id`, `message_id`, `sent_at`. Нужно, чтобы при смене языка в Mini App переписать приветствие, а при новом `/start` — удалить прежнее.

## Наблюдение

На каждый HTTP-запрос сервер считает запросы к базе и их время. Ответ медленнее 200 мс — строка в логе: адрес, время ответа, сколько запросов к базе и сколько они заняли.
