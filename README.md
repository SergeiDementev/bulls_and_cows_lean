# Быки и коровы — облегчённая версия

Логическая игра в Telegram Mini App: сервер загадывает число из разных цифр, игрок угадывает его по подсказкам — 🐂 бык (цифра на своём месте) и 🐄 корова (цифра есть, но на другом месте). Личная статистика и общий рейтинг, русский и английский.

Вторая версия уже выпущенного продукта, написанная с нуля. Цель — проверить, что те же свойства для игрока и та же защита достигаются кратно меньшим объёмом кода, если не строить слои «на вырост». Вся разработка — с ИИ-агентом (Claude Code): агент пишет код и тесты, человек принимает решения и тестирует руками.

## Сравнение с первой версией

Непустые строки, одинаковые правила подсчёта для обеих; код, сгенерированный Prisma, в первой версии не учтён.

| | Первая версия | Облегчённая | Меньше в |
|---|---|---|---|
| Код (сервер, клиент, правила) | 6 507 | 2 784 | 2,3 раза |
| Автотесты | 9 056 | 2 104 | 4,3 раза |
| Документы | 2 778 | 570 | 4,9 раза |
| Инфраструктура и скрипты | 1 835 | 758 | 2,4 раза |
| **Всего** | **20 176** | **6 216** | **3,2 раза** |

Честная оговорка: у первой версии два клиента — чат-бот и Mini App с общей партией, у облегчённой один — Mini App; бот только открывает её.

**Что сохранено:** правила и проверки только на сервере; загаданное число не уходит клиенту, пока партия идёт; вход по подписи Telegram со сроком годности; повтор хода не засчитывается дважды; ограничение частоты; ограничения в самой базе; рейтинг из сводки по индексу; два языка, написанных отдельно; доступность (подписи для VoiceOver, контраст WCAG AA, «уменьшить движение»); HTTPS; ежедневные копии вне сервера с проверенным восстановлением.

**Что убрано и почему ничего не сломалось** — [журнал решений](docs/decisions.md):

| Было | Стало | Почему свойства не потеряны |
|---|---|---|
| Монорепозиторий из пакетов, HTTP между ботом и API, служебные ключи | Один пакет с папками; границы проверяет линтер | Клиент один, внутренних вызовов по сети нет |
| Prisma | Kysely — запросы на TypeScript, выполняется ровно написанное | Prisma съедала 18% процессора и однажды незаметно читала всю таблицу |
| Слой хранилищ с подменой базы в памяти | Сценарии сразу на базе; тесты — на настоящей PostgreSQL | Подмена не нужна, если тестировать на настоящей базе |
| Журнал событий, Grafana, представления для аналитики | SQL-запросы к партиям и ходам | Смотреть дашборды было некому; история со временем ходов на месте |
| Мутационное тестирование, фаззинг, тесты по модели | Примеры и свойства, нарочные поломки на каждом этапе | Тесты — по цене ошибки: нет денег и чужих данных |
| 16 ADR | Строка в журнале решений | Отдельная запись — только для дорогих решений |

## Как устроено

```
Mini App (React) ──HTTPS──► Caddy ──► сервер (Node, Fastify, Kysely) ──► PostgreSQL
                            └─ файлы Mini App          ▲
Telegram ──webhook──────────────────────────────────────┘  бот: /start → правила и «Играть»
```

```
src/domain/   правила игры, статистика, рейтинг — чистые функции, покрытие 100%
src/server/   вход, запросы, сценарии в транзакциях, бот
src/web/      Mini App
src/shared/   типы API и тексты, общие для сервера и браузера
locales/      ru.ftl, en.ftl
```

## Качество

- **Правила** — примеры из документа правил и свойства на случайных данных (fast-check), покрытие 100%.
- **Сервер** — сценарии на настоящей PostgreSQL: подделки входа, одновременные ходы, сводка рейтинга против правил на случайных историях; каждый ответ проверяется на утечку загаданного числа.
- **Mini App** — экраны с подменённым сервером; тексты — одинаковые ключи и подстановки в обоих языках.
- **Сквозные** — рабочая сборка против сервера в Chromium и WebKit, с автоматической проверкой доступности (axe).
- **На каждом этапе** — нарочные поломки кода: тест, который ничего не ловит, найден и исправлен.
- **Нагрузочный замер** — 1000 игроков, база 10 000 игроков ([отчёт](docs/load.md)): нашёл неиспользуемый индекс рейтинга; медиана хода 19 мс, 95% хода в цель не уложились — упирается один процесс сервера, решение записано вместе с сигналом пересмотра.
- **Руками** — партия, VoiceOver на iPhone SE, тёмная тема, «уменьшить движение», восстановление из копии.

CI в GitHub Actions на каждый PR.

## Запуск для разработки

Нужны Node 24, pnpm и Docker Desktop.

```
pnpm install
copy .env.example .env    # вписать пароль базы
pnpm db:up
pnpm check                # формат, линтер, типы, тесты
pnpm test:e2e             # сквозные в Chromium и WebKit
pnpm dev                  # сервер
pnpm dev:web              # Mini App в браузере, вход подписывается сам
```
