# Быки и коровы — облегчённая версия

Логическая игра в Telegram Mini App: сервер загадывает число из разных цифр, игрок угадывает его по подсказкам «быки» и «коровы». Статистика и рейтинг.

Вторая версия уже выпущенного продукта, написанная заново: те же свойства для игрока и та же защита, но без слоёв «на вырост» и кратно меньше кода.

- [Требования](docs/requirements.md)
- [Правила игры и рейтинга](docs/rules.md)
- [Журнал решений](docs/decisions.md) — что убрали по сравнению с первой версией и почему

## Запуск для разработки

Нужны Node 24, pnpm и Docker Desktop.

```
pnpm install
copy .env.example .env    # и заполнить пароль
pnpm db:up
pnpm check
```
